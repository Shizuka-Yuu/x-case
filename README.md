# X-case

ソーシャルメディアコンテンツの分析・研究のためのツールセットです。

## プロジェクト概要

X-caseは、ウェブコンテンツのテキスト解析、画像分析、データ収集を統合した分析プラットフォームです。研究・学術目的での利用を想定しています。

## 主要機能

### 📝 テキスト分析
- コンテンツの自然言語処理
- キーワード抽出と分類
- データの時系列分析

### 🖼️ 画像解析
- OCRによるテキスト抽出
- 画像認識と分類
- ピクセルレベルの色彩分析

### 📊 データ管理
- ウェブリソースからのデータ収集
- アーカイブ機能とバックアップ管理
- 分析結果の整理とエクスポート

## プロジェクト構成

```
X-case/
├── image-analyzer/          # 画像解析ツール
│   ├── index.html          # メインインターフェース
│   ├── js/                 # JavaScriptモジュール
│   └── README.md           # 画像解析ツール詳細
├── analysis_cache/          # 分析結果キャッシュ
├── archive/                # データアーカイブ
├── backup/                 # バックアップデータ
├── Private/                # 非公開設定・データ
├── docs/                   # ドキュメント
├── X-Analysis-Command.md   # 分析コマンド仕様
├── procedure.md            # 手順書
└── README.md              # プロジェクト概要（本ファイル）
```

## 技術スタック

- **フロントエンド**: HTML5/CSS3/JavaScript
- **画像処理**: Tesseract.js, TensorFlow.js
- **データ処理**: Web API, Canvas API
- **バージョン管理**: Git

## 使用方法

1. このリポジトリをクローン
2. `image-analyzer/index.html`をブラウザで開く
3. 分析対象の画像URLを入力
4. 解析結果を確認

## 開発方針

- プライバシー保護：ローカル実行を基本
- 研究目的：学術的なデータ分析を支援
- モジュール設計：機能の独立性を確保
- 拡張性：将来的な機能追加に対応
