# X-case

ソーシャルメディアコンテンツの構造分析・研究プロセスの透明性を担保するためのアーカイブリポジトリです。

## プロジェクト概要

X-caseは、SNS投稿の構造的プロモーション度を客観的に分析し、アーカイブとして保管・視覚化するウェブアプリケーションです。研究・学術目的での利用を想定しています。
本リポジトリはOSS（オープンソースソフトウェア）としての共同開発プロジェクトではなく、**「どのような観点と基準で分析が行われているか」という研究の透明性を担保すること**を目的として公開されています。

## 公開・秘匿の方針

評価の恣意性を排除し、研究プロセスを公開することで透明性を確保していますが、分析システムの悪用（意図的なアルゴリズムハック等）を防ぐため、一部のコアシステムは秘匿されています。

* **公開しているもの**:
  * アーカイブされたケースデータ（JSON/Markdown）
  * データを視覚化するためのフロントエンドビューア（HTML/CSS/JS）
  * 画像解析用のフロントエンドツール
  * 分析の基本哲学や大枠の評価項目
* **秘匿しているもの（非公開）**:
  * AIエージェントを駆動させる具体的な実行パイプラインやプロンプト
  * エンゲージメント指標の精密な計算式（内部アルゴリズム）
  * 分析対象としている特定のSNSプラットフォーム名

## 研究目的

本プロジェクトは、ソーシャルメディアコンテンツの構造的特徴とエンゲージメントの関係性について、以下の観点から研究することを目的としています。

### 分析対象
- **投稿構造**: 論理構造、意図されたユーザー行動（クリック、シェア等の誘導）
- **エンゲージメント**: 各種リアクション（返信、共有、保存等）の比率と偏り
- **アルゴリズム適応**: 滞在時間生成因子、インタラクション誘導の評価
- **プロモーション度**: 構造的自己プロモーションとしての機能度（スコア化）

### 研究手法
- **定量的分析**: エンゲージメント数値の統計的処理
- **定性的分析**: 投稿内容の構造的解釈
- **比較分析**: 複数ケース間のパターン比較
- **時系列分析**: 同一投稿者の変遷追跡

## 分析手法の大枠

### 構造的プロモーション度評価
- **論理構造分析**: 投稿の構成と意図の解釈
- **エンゲージメント比率**: 議論密度（Controversy Ratio）、保存実用価値などの算出
- **アルゴリズム適応**: 滞在時間の推計、インタラクション誘導の評価
- **文脈整合性**: 複数投稿間の一貫性分析

### データ収集
- **トレンド分析**: 特定のカテゴリにおけるトップ投稿群の連続分析
- **スポット分析**: 研究者が任意に選定した投稿の単発分析
- **構造化収集**: 定められたテンプレートに基づくデータ取得とJSON化
- **メディア分析**: 画像・動画コンテンツの解析と構造判定への組み込み

## 倫理的配慮と免責事項

### 倫理的配慮
- **プライバシー尊重**: 誰でもアクセス可能な公開情報のみを分析対象とします。
- **客観性の維持**: 個人を特定した攻撃や批判を回避し、あくまで「ポストの骨格・構造」に対する客観的な分析に徹します。

### 免責事項
本プロジェクトは研究・学術目的での使用を前提としています。アーカイブに記録された分析結果は、AIエージェントによる観測可能なデータの推論・構造解釈を示すものであり、対象ポストの投稿者の個人的な意図や思想を断定、あるいは批判するものではありません。

## 分析結果の発信について

抽出された分析結果は、専用アカウントを通じて「分析の皮を被ったエンタメ」として発信・検証を行っています。

- **アカウント**: [@XCaseJP](https://x.com/XCaseJP)
- **活動内容**: SNS上のバズ投稿をCase形式で解剖し、構造・意図・虚実を検証
- **リクエスト**: 分析希望のポストは、同アカウントのDMまたは固定ポストへのリプライにて受け付けています
