# X-case

X（旧Twitter）のポストを包括的に分析するためのツールセットです。

## プロジェクト概要

X-caseは、Xポストのテキスト解析、画像分析、データ収集を統合した分析プラットフォームです。研究者、マーケティング担当者、コンテンツクリエイター向けに開発されました。

## 主要機能

### 📝 テキスト分析
- ポスト内容の自然言語処理
- 感情分析とキーワード抽出
- トレンド分析と時系列データ

### 🖼️ 画像解析
- OCRによるテキスト抽出
- 物体認識と画像分類
- ピクセルレベルの色彩分析

### 📊 データ収集
- X API連携によるデータ取得
- アーカイブ機能とバックアップ管理
- 分析結果のエクスポート

## 技術スタック

- **フロントエンド**: HTML5/CSS3/JavaScript
- **画像処理**: Tesseract.js, TensorFlow.js
- **データ処理**: Web API, Canvas API
- **バージョン管理**: Git

## 使用方法

1. このリポジトリをクローン
2. `image-analyzer/index.html`をブラウザで開く
3. 分析したいXポストの画像URLを入力
4. 解析結果を確認
