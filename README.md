# X-case

ソーシャルメディアコンテンツの構造分析・研究のためのアーカイブビューアです。

## プロジェクト概要

X-caseは、X（Twitter）投稿の構造的プロモーション度を分析し、視覚的に表示するウェブアプリケーションです。研究・学術目的での利用を想定しています。

## 主要機能

### � ケースアーカイブビューア
- 分析済みケースの一覧表示と検索
- 日付・投稿者別のフィルタリング
- ソート機能（日付順、名前順）

### 📈 構造的判定分析
- プロモーション度の視覚的表示（プログレスバー）
- スコアに応じた動的背景画像変更
- エンゲージメント指標の詳細表示

### 🖼️ 画像解析ツール
- OCRによるテキスト抽出
- 画像認識と分類
- ピクセルレベルの色彩分析

### � データ管理
- ケースデータのアーカイブ機能
- JSON形式の分析結果管理
- プレビュー画像生成機能

## プロジェクト構成

```
X-case/
├── index.html              # トップページ（アーカイブ一覧）
├── case.html               # ケース詳細ページ
├── js/                     # JavaScriptモジュール
│   ├── config.js           # 設定ファイル
│   ├── index.js            # トップページ用スクリプト
│   └── case.js             # ケース詳細ページ用スクリプト
├── docs/                   # スタイルシート
│   ├── styles.css          # トップページ用
│   └── case-styles.css     # ケース詳細ページ用
├── img/                    # 背景画像リソース
│   ├── low.webp            # 低スコア用背景
│   ├── normal.webp         # 通常スコア用背景
│   ├── mid.webp            # 中スコア用背景
│   └── high.webp           # 高スコア用背景
├── image-analyzer/         # 画像解析ツール
│   ├── index.html          # 画像解析インターフェース
│   └── js/                 # 画像解析用スクリプト
├── archive/                # 分析データアーカイブ
│   └── 2026-05-*/          # 日付別ケースデータ
├── analysis_cache/         # 分析結果キャッシュ
├── template/               # テンプレートファイル
├── backup/                 # バックアップデータ
└── Private/                # 非公開設定・データ
```

## 技術スタック

- **フロントエンド**: HTML5/CSS3/JavaScript (ES6+)
- **画像処理**: Tesseract.js, TensorFlow.js
- **データ処理**: Fetch API, Canvas API
- **スタイリング**: CSS Grid, Flexbox, CSS Transitions
- **バージョン管理**: Git

## 使用方法

### アーカイブビューア
1. このリポジトリをクローン
2. `index.html`をブラウザで開く
3. ケース一覧から分析対象を選択
4. モーダルまたは詳細ページで結果を確認

### 画像解析ツール
1. `image-analyzer/index.html`をブラウザで開く
2. 分析対象の画像URLを入力
3. 解析結果を確認

## 機能詳細

### 構造的判定
- **プロモーション度**: 0-100%のスコアで表示
- **視覚的フィードバック**: スコアに応じた色と背景画像
- **詳細分析**: エンゲージメント指標と構造的要因の表示

### アーカイブ機能
- **検索**: ケース名、投稿者、内容で検索
- **フィルタリング**: 年月別での絞り込み
- **ソート**: 日順、名前順での並び替え
