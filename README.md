# X-case

ソーシャルメディアコンテンツの構造分析・研究のためのアーカイブビューアです。

## プロジェクト概要

X-caseは、X（Twitter）投稿の構造的プロモーション度を分析し、視覚的に表示するウェブアプリケーションです。研究・学術目的での利用を想定しています。

## 主要機能

### � ケースアーカイブビューア
- 分析済みケースの一覧表示と検索
- 日付・投稿者別のフィルタリング
- ソート機能（日付順、名前順）

### 📈 構造的判定分析
- プロモーション度の視覚的表示（プログレスバー）
- スコアに応じた動的背景画像変更
- エンゲージメント指標の詳細表示

### 🖼️ 画像解析ツール
- OCRによるテキスト抽出
- 画像認識と分類
- ピクセルレベルの色彩分析

### � データ管理
- ケースデータのアーカイブ機能
- JSON形式の分析結果管理
- プレビュー画像生成機能

## 使用方法

### 分析開始前の準備
1. `X-Event-Analyzer-v2.0-Algorithm-Summary.md` を参照し、分析フレームワークを理解
2. `procedure/X-Analysis-Procedure.md` を確認し、最新の分析手順を把握
3. 全体のワークフローを理解

### アーカイブビューア
1. このリポジトリをクローン
2. `index.html`をブラウザで開く
3. ケース一覧から分析対象を選択
4. モーダルまたは詳細ページで結果を確認

### 画像解析ツール
1. `image-analyzer/index.html`をブラウザで開く
2. 分析対象の画像URLを入力
3. 解析結果を確認

## 機能詳細

### 構造的判定
- **プロモーション度**: 0-100%のスコアで表示
- **視覚的フィードバック**: スコアに応じた色と背景画像
- **詳細分析**: エンゲージメント指標と構造的要因の表示

### アーカイブ機能
- **検索**: ケース名、投稿者、内容で検索
- **フィルタリング**: 年月別での絞り込み
- **ソート**: 日順、名前順での並び替え

## 研究目的

このプロジェクトは、ソーシャルメディアコンテンツの構造的特徴とエンゲージメントの関係性について、以下の観点から研究することを目的としています：

### 分析対象
- **投稿構造**: 論理構造、意図されたユーザー行動
- **エンゲージメント**: 返信、リポスト、いいね、ブックマークの比率
- **アルゴリズム適応**: 滞在時間生成因子、インタラクション誘導
- **プロモーション度**: 構造的自己プロモーションとしての機能度

### 研究手法
- **定量的分析**: エンゲージメント数値の統計的処理
- **定性的分析**: 投稿内容の構造的解釈
- **比較分析**: 複数ケース間のパターン比較
- **時系列分析**: 同一投稿者の変遷追跡

### 学術的貢献
- **構造的分類**: コンテンツのプロモーション度分類手法
- **エンゲージメント理論**: ソーシャルメディアでの対話生成モデル
- **アルゴリズム理解**: プラットフォーム推薦システムの特性分析

## 開発方針

- **プライバシー保護**: ローカル実行を基本
- **研究目的**: 学術的なデータ分析を支援

- **拡張性**: 将来的な機能追加に対応

## 分析手法

### 構造的プロモーション度評価
- **論理構造分析**: 投稿の構成と意図の解釈
- **エンゲージメント比率**: Controversy Ratio、Utility Score等の算出
- **アルゴリズム適応**: 滞在時間、インタラクション誘導の評価
- **文脈整合性**: 複数投稿間の一貫性分析

### データ収集
- **インスピレーション分析**: Xインスピレーションページのトップ投稿を主対象
- **手動収集**: 研究者が対象投稿を選定
- **構造化収集**: 定められたテンプレートに基づきデータ取得
- **メディア分析**: 画像・動画コンテンツの専門的解析
- **時系列追跡**: 同一アカウントの変遷記録

## 倫理的配慮

- **プライバシー尊重**: 公開情報のみを分析対象
- **匿名性確保**: 個人特定の回避
- **研究目的限定**: 商業利用の禁止
- **透明性**: 分析手法の公開（ただしアルゴリズムは除く）
